# Roadmap

## Milestone 0 — Bootstrap

Tasks 001-004 establish solution quality gates, domain contracts, configuration, diagnostics, and the MVVM shell.

## Milestone 1 — Local text acquisition

Tasks 005-010 implement window discovery, Windows Graphics Capture, region selection, preprocessing, PaddleOCR, and temporal text stabilization.

## Milestone 2 — Translation intelligence

Tasks 011-016 add provider contracts, OpenAI-compatible/Ollama/custom adapters, glossary, translation memory, and orchestration/backpressure.

## Milestone 3 — Player experience

Tasks 017-020 deliver overlay behavior, profiles/settings, hotkeys/session controls, and privacy/onboarding.

## Milestone 4 — Hardening and release

Tasks 021-025 cover persistence migrations, observability, tests/performance, packaging/update readiness, and release documentation.

## Post-V1 candidates

- Additional local translation engines and OCR backends.
- Multi-region layout intelligence, advanced typography, and per-game community profile import.
- Accessibility improvements and localization of the desktop UI.

Audio, STT, TTS, process injection, memory hooks, graphics hooks, anti-cheat bypass, and game-file modification are not implied by this roadmap and require a separate product/security review if ever considered.
